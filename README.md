# 自動仙寵－保駕護航

AutoXianPet 的 Windows 11 x64 發行頁。請到 [Releases](https://github.com/NCshop-bc/AutoXianPet-Releases/releases) 下載最新正式版的 `AutoXianPet.exe`，放到可寫入的資料夾後雙擊啟動。

下載後可在 PowerShell 執行 `Get-FileHash .\AutoXianPet.exe -Algorithm SHA256`，並將結果與同版本的 `AutoXianPet.exe.sha256` 比對。

程式啟動後會查詢新版，並在停止監控後才套用更新。角色與模擬器設定保存在 `%APPDATA%\MuMuHPMPMonitor`。
